# PROJECT ARTWORK - TEMPORARY PLACEHOLDERS

Every project image in this folder is **temporary artwork**, not Keshav's finished work.
Each one is a category-specific SVG illustration generated by `tools/generate-artwork.js`,
labelled as temporary in-image.

## Requirements
- Format: JPG or WebP (keep the filenames, or update the paths in `index.html`
  **and** in the `PROJECTS` object in `js/script.js`)
- Quality: a real frame/still from the finished piece

Project titles, descriptions, tools and process notes live in the `PROJECTS` object
in `js/script.js` - it feeds the gallery cards, the featured block and the details modal.
